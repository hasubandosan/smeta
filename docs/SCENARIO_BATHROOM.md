# Сквозной сценарий ванной (Фаза 12)

Тест: `node tests/scenario.test.js [путь\к\stroysmeta-kb.json]`. Без аргумента берёт вымышленный справочник; с реальным файлом проверяет то же на настоящих темах (файл в репозиторий не входит). Данные технологий в тесте вымышленные (цены, расход, паузы — только для проверки цепочки, не нормы).

## Что проходит тест (цепочка работает)
1. Тестовая ванная (`seeds.js`) → технологии «2.5.6 Стяжка», «3.2.1 Гидроизоляция», «3.2.2 Плитка» → связь со справочником по номеру этапа.
2. Нормы из справочника показаны, ничего не подтверждено, расход/цены неизвестны; смета и закупка честно «неполные».
3. Статусы процессов по правилам; начать стяжку нельзя, пока не сделано то, что «до».
4. Человек вводит расход и цены → смета (площадь пола из геометрии), закупка (упаковки, ₽); пункт плана на старой версии технологии → «Обновить до текущей».
5. Паузы: пока дни не введены — время неизвестно; после ввода — «от…до»; нарушенный порядок → предупреждение.
6. Выполнение: работа → выполнено → приёмка (не пускает без отметок, замеры пишутся) → состояние поверхности меняется (стяжка YES, плитка YES); остаток неизвестен, пока неизвестно «куплено».

## Найдено и исправлено в v0.22.0 (нарушения D3)
- Неизвестная цена операции считалась как 0 ₽ и итог не помечался неполным. Теперь работа = неизвестно, итог неполный.
- В «Закупке» и «Остатке» материал с неизвестным расходом показывался нулями. Теперь «?» / «≥ известной части», стоимость — неизвестна.

## Порядок пола (решено, D34, v0.23)
Демонтаж → тёплый пол → стяжка → гидроизоляция по стяжке → плитка (по справочнику 2.5.5, 2.5.6, 3.2.1, 3.2.2). Защитная гидроизоляция плиты под стяжкой — рекомендуемый шаг, остальное не блокирует. Тест проходит именно в этом порядке.

## Открыто
1. **Процессы санузла вне «пол/стены/потолок/короб».** В библиотеке нет: планировка и эргономика, черновая сантехника и инсталляция, электрика, чистовая сантехника, герметизация. Для них движку нужен вид поверхности «инженерия помещения» и автоматическое создание поверхностей по геометрии («поверхности из геометрии»; понадобится и CAD-модулю). Это следующий срез основного бота; состав и порядок процессов предлагает бот по справочнику, владелец подтверждает.
2. Гидроизоляция стен (заход на стены, мокрая зона) в состоянии стен не моделируется.
3. Нормы расхода, цены и паузы для стяжки, гидроизоляции и плитки вводятся руками (мастер норм, вкладка «Маршруты»); справочник их не подставляет.
