# Журнал решений

Формат: номер, дата, решение, причина. Новое решение — в конец. Отменять старое только новой записью.

- **D1 · 2026-10-08 · Старое приложение v0.5 не святыня.** Его можно заменить новой моделью; данные пользователя при этом переносим миграцией (ТЗ §23), а не выкидываем. Новый код в `js/`, `app.js` не растим.
- **D2 · 2026-10-08 · Много файлов `js/`, без сборки и без ES-модулей.** Классические `<script>` + глобал `SM`, каждый файл работает и в Node для тестов. Отменяет прежнее «три файла» из старого AGENTS.md.
- **D3 · 2026-10-08 · Неизвестное = `null`, не 0.** Расчёт с неизвестным входом даёт «неизвестно» и список недостающих данных (ТЗ §2, UNKNOWN != NO).
- **D4 · 2026-10-08 · Геометрия — контур стен «черепашкой»** (длина + поворот), не координаты. Причина: пользователь вводит размеры рулеткой, правка длины должна пересчитывать всё; координаты выводятся.
- **D5 · 2026-10-08 · Формулы: текст → AST, свой интерпретатор.** Без `eval`. Единицы на первом этапе — метки и таблица пересчёта, не полная проверка размерностей.
- **D6 · 2026-10-08 · Не выдумываем строительные данные.** Нормы расхода, цены, упаковки брендов — только от пользователя; иначе `null`/UNKNOWN и вопрос (ТЗ §21).
- **D7 · 2026-10-08 · Тестовая ванная (ТЗ §21) — данные в seed, не код.** Раскладка 6 стен (углы, что такое «fortan») ещё не подтверждена владельцем → seed ванной откладывается до ответа. Пока тесты используют прямоугольник и Г-образную комнату.
- **D8 · 2026-10-08 · Работа ведётся разными ИИ-ботами через патчи.** Каждый бот обязан читать `AGENTS.md` → `ARCHITECTURE.md` → `ROADMAP.md` → `DECISIONS.md` и в конце обновить их и `CHANGELOG.md`.
