# Журнал CAD-модуля
## 0.5.0 — срез 5: несколько помещений на плане
Ядро: `ops.moveRoom, rotateRoom, linkWalls, unlinkWall, alignRoomToWall`, `snapRoomMove` (привязка угол-к-углу и стена-к-стене), `findSharedWalls` (P19–P22). Интерфейс: метка в центре выбранной комнаты — перенос мышью/пальцем с привязкой к соседям (и к сетке), положение и поворот числом и кнопками ⟲ ⟳ 90°, «Найти общие стены» + «Связать», блок «Общая стена» в панели стены (связь, «Разорвать связь», «Прижать комнату к другой стене…»), связанные стены рисуются синим. Дополнительно: «Поставить кликом на плане» для нового проёма. Тесты: `tests/planner-rooms.test.js` (10), `tests/planner-ui-rooms.test.js` (9).

## 0.4.0 — срез 4: проёмы
Ядро: `ops.addOpening, moveOpening, setOpeningProps, attachOpening, detachOpening, removeOpening` (P16–P18). Интерфейс: панель проёма (вид, ширина, высота, низ от пола, расстояние от начала стены, открывание), красная ручка перетаскивания вдоль стены (мышь/касание, привязка к сетке), дуга открывания, добавление проёма из панели стены, привязка проёма без стены — выбором стены и числом или кликом по стене на плане, отвязка, удаление. Ошибка ввода больше не стирает уже набранные поля панели. Тесты: `tests/planner-open.test.js` (9), `tests/planner-ui-open.test.js` (10).

## 0.3.0 — срез 3: правка стен
Ядро: `SM.planner.ops` (`moveVertex`, `setWallLength`, `setVertexAngle`, `splitWall`, `removeVertex`, `setWallProps`, `setRoomProps`, `addRoomRect/L/FromPoints`, `splitRoom`, `removeRoom`), `vertexAngle`, `nearestOnContour`, `toLocal`; комната не прыгает при правке (P9). Интерфейс: ручки углов (мышь/касание), панель числового ввода (длина, угол, толщина, разделение, название, высота), «＋ Комната», перегородка кликами, отмена/повтор (кнопки, Ctrl+Z/Y), привязка к сетке, `onChange`. Стенд: режим правки, выбор шага сетки. Тесты: `tests/planner-edit.test.js` (16), `tests/planner-ui-edit.test.js` (15).

## 0.2.0 — срез 2: просмотр
`js/planner-ui.js` (`SM.planner.mount`, только чтение: помещения, стены с толщиной, проёмы, предметы, размеры, сетка, масштаб/сдвиг мышью и касанием, выбор), `planner.html` (стенд: эталонная ванная, вымышленный пример из 3 помещений, панель свойств, замечания, список проёмов без привязки), `SM.planner.describe`. Тесты `tests/planner-ui.test.js` (10 проверок, jsdom).

## 0.1.0 — срез 1: ядро
`js/planner.js`: `fromGeometry`/`toGeometry`, `moveVertex`, `snapPoint`, `toWorld`, `finish`, `measure`, `createHistory`. Тесты `tests/planner.test.js` (15 проверок): эталонная ванная (контур, 15,75 м²), round-trip без потерь, произвольные углы, неизвестная длина, привязка, undo/redo.
