# Запросы CAD-модуля к контракту
Формат записи: что нужно · зачем · пример данных. Отвечает основной бот.

## 1. `opening.hinge` — сторона петель
**Что:** необязательное поле проёма `hinge: 'start' | 'end' | null` — у какого конца проёма (по обходу стены) шарнир двери.
**Зачем:** дуга открывания рисуется правильной стороной; сейчас шарнир условно у начала (P17).
**Пример:** `{id, wallId, kind: 'дверь', w: 0.9, at: 0.5, swing: 'in', hinge: 'end'}`. Без поля — как сейчас (неизвестно, рисуем у начала).
