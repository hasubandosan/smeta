# Журнал изменений

Формат: новые версии сверху. Версия в `APP_VERSION` (app.js) должна совпадать с верхней записью.
Каждое изменение проекта (человеком или ИИ-агентом) обязательно добавляет запись сюда — см. правила в `AGENTS.md`.

Шаблон записи:

```
## X.Y.Z — ГГГГ-ММ-ДД — кто (человек / название ИИ)
### Добавлено / Изменено / Исправлено / Удалено
- что и зачем (одна строка на пункт)
### Данные
- изменилась ли схема данных и что делает migrate()
### Проверка
- как проверено (tests/smoke.js, вручную)
```

## 0.15.0 — 2026-10-15 — Claude
### Добавлено
- `js/fact.js` (`SM.fact`): фактический объём и стоимость по операциям, расход материалов по работам, отчёт «план против факта» с отклонениями.
- Вкладка «Работы»: после начала работы вносится факт (объём, ₽, расход материалов); итог по начатым работам; у принятой работы факт закрыт.
- Вкладка «Закупка»: колонки «Израсходовано» и «Остаток», пометка «больше, чем куплено», расход материалов вне сметы.
- Вкладка «Смета»: «Утвердить текущую смету» — неизменяемый снимок; список снимков со сравнением с текущей сметой (итог, добавленные/убранные/изменённые операции).
### Изменено
- Факт смету не меняет (смета ≠ источник истины). Неуказанный факт = неизвестно, а не 0; итог факта считает только известное и честно помечает неполноту.
### Данные
- Необязательные поля `plan[].fact` и `S.approved[]`; `normalize` добавляет `approved: []` старым проектам. Схема не менялась.
### Проверка
- `node tests/core.test.js` (36), `node tests/storage.test.js` (17), `node tests/fact.test.js` (9, новый), `node tests/ui.test.js`, `node tests/smoke.js`.

## 0.14.0 — 2026-10-15 — Claude
### Добавлено
- `js/storage.js` (`SM.store`): хранение проекта, точки отката (последние 10, не чаще раза в 5 минут и перед любой заменой данных), копия `:backup` при загрузке, экспорт/импорт JSON с проверкой, облако GitHub Gist, листы Excel.
- Вкладка «Данные» в `new.html`: скачать копию (JSON), загрузить копию, смета в Excel (листы «Смета», «Закупка», «Помещения», «Работы»), список точек отката с восстановлением, подключение облака (сверить / отправить / загрузить / автоотправка).

- Загрузка и сохранение в `ui.js` идут через `SM.store`. Переключение вкладок больше не меняет штамп `updated` (раньше любой клик «сохранял»).

### Данные
- Схема не менялась. Новые ключи localStorage: `stroysmeta:model:snaps` (точки отката), `stroysmeta:model:sync` (токен и состояние облака; в проект и экспорт не попадает). Необязательное поле `updated` в проекте (штамп последнего изменения).
### Проверка
